추상 자료형(ADT)?

- 정수형 분자(numerator)와 분모(denominator)로 이루어진 분수를 표현하고, 분수의 사칙연산 결과를 항상 기약분수로 제공한다.

자료(데이터) 정의?

- 분수는 다음 두 정수로 구성된다.
  num : 분자 (정수)
  den : 분모 (정수, 단 den != 0)
- 분수의 표준 형태(정규화)
  기약분수 상태(분자와 분모의 최대공약수가 1)
  분모는 양수(den > 0). 만약 음수면 분자에 부호를 옮긴다.

제공 연산(Operations)?

1. 생성/정규화
   reduce(f) : 분수 f를 받아 기약분수로 만들어 반환한다.
   입력: 분수 f(num, den) (den != 0)
   출력: 기약분수 형태의 분수

2. 사칙연산 (결과는 모두 기약분수)
   add(a, b) : a + b
   sub(a, b) : a - b
   mul(a, b) : a \* b
   div(a, b) : a / b (단, b.num != 0)
   각 연산은 분수 2개를 입력받아 분수 1개를 반환하며, 반환 값은 기약분수이다.

3. 문자열 변환
   from_string("A/B") : "A/B" 형태 문자열을 분수로 변환
   A, B는 정수이며 B는 0이 될 수 없다.
   print(f) : 분수 f를 "A/B" 형태로 출력한다.
